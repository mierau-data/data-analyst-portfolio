# Проверка гипотез в Python и результаты A/B-теста

> **Учебный проект** курса «Аналитик данных» Яндекс Практикум, 2026. Две части: проверка статистической гипотезы на данных сервиса Яндекс Книги и оценка результатов A/B-теста интернет-магазина.

## Задача

**Часть 1 — Яндекс Книги.** Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы.

**Часть 2 — BitMotion Kit.** Оценить результаты A/B-теста `interface_eu_test`: новая упрощённая версия сайта должна была повысить конверсию зарегистрированных пользователей в покупателей минимум на 3 процентных пункта в течение 7 дней после регистрации. Нужно проверить корректность проведения теста и проанализировать результаты.

## Данные

**Часть 1:** `yandex_knigi_data.csv` — пользователи Москвы и Санкт-Петербурга с суммой часов активности.

**Часть 2:**
- `ab_test_participants.csv` — участники теста: `user_id`, `group`, `ab_test`, `device`;
- `ab_test_events.csv` — события 2020 года: `user_id`, `event_dt`, `event_name`, `details` (стоимость привлечения/покупки и зона пользователя).

## Стек

Python, Pandas, Matplotlib, SciPy, statsmodels, Jupyter Notebook.

## Что сделано

**Часть 1 — проверка гипотезы:**
- загрузка данных, проверка и удаление дубликатов по `user_id` (244 записи);
- сравнение размеров групп и описательных статистик (Москва — 6 234, Санкт-Петербург — 2 306 пользователей);
- односторонний двухвыборочный t-тест (`ttest_ind`, `alternative='greater'`) при α = 0.05;
- аналитическая записка с интерпретацией результата и возможными причинами.

**Часть 2 — оценка A/B-теста:**
- загрузка данных участников и событий, проверка целостности;
- проверка корректности теста: распределение по группам, отсутствие пересечений, соответствие ТЗ;
- расчёт достаточности выборки (базовая конверсия 30%, мощность 80%, достоверность 95%);
- расчёт конверсии в покупку по группам, абсолютного и относительного прироста;
- двусторонний z-тест для двух пропорций при α = 0.05;
- вывод и бизнес-рекомендация с учётом целевого показателя из ТЗ.

## Ключевые выводы

**Часть 1.** T-статистика 0.4174, **p-value = 0.3382** — значительно больше α = 0.05. Нулевая гипотеза не отвергается: статистически значимого различия в средней активности между пользователями Санкт-Петербурга и Москвы **не обнаружено**. Гипотеза о более высокой активности петербуржцев не подтвердилась.

**Часть 2.** Выборки достаточны и сопоставимы. Конверсия группы B (новый интерфейс) — 31.17%, группы A (старый) — 28.98%, прирост +2.19 п.п. (+7.56%). Двусторонний z-тест дал Z = 2.3867, **p-value = 0.0170 < 0.05** — различие статистически значимо, эффект не случаен. Однако целевой прирост в ≥ 3 п.п. по ТЗ **не достигнут**. Рекомендация: внедрять новый интерфейс в текущем виде нецелесообразно — эффект положительный, но недостаточный для заявленной цели; стоит доработать интерфейс и повторить тест.
